# Studio 项目归档、完成态筛选与安全复制（#109 F1/F2）

项目列表新增「当前 / 已完成 / 已归档 / 全部」筛选；默认显示未归档项目，已完成指至少有一个 Shot 且所有 Shot 状态为 done。归档仅修改项目索引内的可选 `archived` 标志，可以取消，不删除文件、任务和结果。旧项目缺少 `archived` 字段时默认为 false。

项目详情菜单支持「复制项目制作计划」：复制剧本、风格、配置、参考素材引用和一致性档案，创建全新的项目和 Shot ID；**清空旧 taskId、Take、选定结果、运行状态、尾帧和时间线**。新镜头回到 Draft；再次执行任何云工作流仍须主动进入生成页并接受付费确认。跨项目引用同一个应用持有的源素材时，已有引用保护会防止过早 GC 原件。

复制项目是**安全重新制作**而非完整迁移或备份：它不复制成片、旧生成结果或历史任务，不能代替 #109 A2 的 ZIP 项目导入导出。JVM 回归覆盖旧索引兼容、归档重启、状态过滤及运行任务安全复制。
