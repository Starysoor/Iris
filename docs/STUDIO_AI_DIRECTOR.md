# Studio AI 导演 · 结构化镜头建议（#101）

> 此功能只生成**可审核的本地镜头草稿**，不会自动调用视频生成 API、付费、修改已经选定的 Take 或删除项目数据。

## 使用

1. 在 Studio 项目中填入剧本、风格、角色/场景档案、参考素材和目标时长。
2. 到“AI 导演”请求镜头建议。助手仅能使用项目中存在的参考图片 ID 及**当前已配置的工作流路径**。人物、装束、场景的外形描述需要由用户提供；文字 AI 不会凭空看懂尚未解析的图片内容。
3. 检查生成的镜头建议：画面、运镜、叙事秒数、引用图片数量、建议模型路径（**只是提示**）、来源依据及风险。引用无效图片的条目默认不选中，并显示错误。
4. 点击“编辑镜头”可修正画面提示、镜头语言、预期秒数，并勾选真实项目图片；勾选需要提交的建议，最后点击应用。
5. 应用时使用原子项目索引写入，保留原有镜头和尾帧自动接力，**只写入新草稿**。参考 ID、图片类型、项目修改时间均会再次检查；校验失败不会部分写入。

## 结构化输出

优先要求 `schemaVersion=1` 的 JSON 文档：

```json
{
  "schemaVersion": 1,
  "shots": [
    {
      "prompt": "紫裙舞者在仪式大厅停顿，慢慢转身",
      "cameraNotes": "手部特写推向面部、再切中景",
      "durationSeconds": 8,
      "referenceAssetIds": ["当前项目中实际存在的图片ID"],
      "workflowPath": null,
      "rationale": "依据已有角色设定和相邻镜头",
      "risk": "8秒可能需要分段生成并通过切镜衔接"
    }
  ]
}
```

解析器保留旧版 `序号 | 画面 | 运镜 | 秒数` 行格式兼容。JSON 版本不符合 v1 时拒绝作为有效计划，而不是猜测字段。建议中的收费信息、模型支持的参考数量等仍然要在已配置 Provider 的**真实输入契约**预检中确认。

## 目前限制

- “AI 推荐模型”是**待人工核验的文本建议**，不会替用户改变工作流或擅自提交。
- 文本上下文依赖已命名的角色/场景/素材描述；尚未自动对图片做视觉理解，也没有自动逐帧理解完整视频。
- 计划叙事秒数不等于单段视频输出时长；如果模型每次只支持 5 秒，请自行拆段/切镜。
- 完整 120 秒/12 镜头、有声、多模型/多 Take 真机项目验收仍归 [#80](https://github.com/Starysoor/Iris/issues/80)，不得用此文本建议功能或短视频模拟器冒充已完成。
