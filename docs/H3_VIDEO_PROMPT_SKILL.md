# MiniMax H3 视频扩写内建技能

对应 Issue #121。

## 入口与兼容性

「创作」页仍使用原有 AI 技能按钮与 GenerateViewModel.aiExpand() 的单轮文本模型请求，不改变 UI 层级、任务提交、计费与预算门禁。新增内建技能 builtin_h3_video（「H3 视频扩写」），已有用户升级后由 AiSkillDef.mergeBuiltins() 自动补充，并保留此前编辑的内建技能与所有自定义技能。

工作流**名称或路径**包含 minimax / h3 时，会在可用技能列表优先显示「H3 视频扩写」。覆盖 AutoDL 工作流、AutoDL 模型直连和 SiliconFlow MiniMax-H3。用户配置的技能过滤规则优先，若主动屏蔽则不强行展示。SDXL / Anima / Pony 图像工作流仍优先图像标签技能，其他图像工作流仍优先自然语言扩写。

## H3 输出约定

MiniMax 官方三段式：
- integrated_multimodal_description：英语叙述按播放顺序发生的主体动作、镜头、场景、对白和场内声。
- overall_soundscape：1–4 句环境/动作/非语言声，不重复对白。
- non_diegetic_music：1–3 句配乐乐器、节奏、速度和动态；明确要求「无配乐 / 只要音效」时输出 N/A，保留场内音效。

根据用户文字中明确提供的参考模式自动选择：
- T2VA 文生视频：不加图片对齐行，直接三段式。
- I2VA 首帧：图 1 与 0.00 秒对齐，从既有画面状态向前发展。
- FL2VA 首尾帧：图 1 与 0.00 秒、图 2 与视频终点 S.SS 秒对齐；重点描述主体/机位/环境从开始到结束的连续变化。默认单镜头，不重述两张静帧。
- L2VA 尾帧：图 1 与视频最后时刻对齐，描述如何收敛到结尾画面。

文本主体使用英语；用户给出的对白和画面文字原文保留，说话人用稳定 (S1)/(S2) 编号，画外音注明嘴唇闭合。只描述可看见或听到的内容；微小景别变化用运镜表达，不混淆为切镜，不堆砌 Danbooru 标签。

**无时长不虚构：** 首尾帧模式缺少目标时长时保留 S.SS 待填写；使用前需替换为实际生成时长。AI 扩写仅使用当前文本，不会假称已经观察尚未传入的首尾图片。为保证模式选择正确，应在扩写文本里明确「首尾帧已给出」等上下文。

## 范围与局限

- 属于提示词整理模板，不是 MiniMax 视频 API 兼容性认证；各托管服务是否支持三段结构需逐个确认。
- 扩写只会通过原先配置的 AI 文本端点进行一次请求，可能产生用户已配置的 API 费用，但不增加后台自动生成或额外付费操作。
- JVM 测试保障技能注册、迁移、优先排序和提示词关键结构；真实模型生成效果仍需用户配置端点验证。
- 官方指南可能随版本更新，若不一致，以官方最新版为准：
