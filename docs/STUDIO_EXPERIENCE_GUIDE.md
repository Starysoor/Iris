# Iris Studio：从剧本到有声成片（Issue #101 第一阶段）

此文档适用于 `feat/101-studio-experience` 分支合并后的版本；**v2.4.0-beta.1 APK 仍是先前基线，不含这些新增交互**。本文说明已在代码里落地的功能和明确的边界。

## 核心路线

1. 打开 **项目**，新建空白项目；可以先离线写剧本与分镜，未配置模型不影响创建。项目首页的“下一步怎么做”依据实际镜头和时间线给出行动入口。
2. 选择 **组合工作流**：
   - 文字分镜 → 视频 → 剪辑；
   - 参考图库 → 首尾帧接力 → 剪辑；
   - 关键帧图 → 视频 → 配音音效 → 剪辑。
3. 每阶段分别选择图像、视频或音频云模型并保存。系统只允许选已配置且目录中明确声明为该类的模型；本地 ComfyUI 通过 **创作** 页执行。**这是用户控制的分步配方，不是自动连线的跨厂商节点工作流。**
4. 点击某阶段 **进入生成**，在原 **创作** 页检查真实模型合同、字段、参考图上传、持续时间/比例/费用等；任务提交仍受统一厂商收费确认和项目预算门禁约束。选择流程配方或打开阶段 **不会自动执行**、重试或支付。
5. 去 **任务** 中用“全部项目 / 独立任务 / 作品名”过滤；使用原有进度、取消、恢复与查看功能。从镜头进入创作时可看到作品关联，点击“返回项目”即可返回。
6. **结果** 页的“加入项目”可选择：作为角色/场景等参考素材；**视频加入指定 Shot 的候选 Take**（不会取代已有主 Take）；**视频/音频直接加入项目时间线**。执行后可点击提示返回项目。导入和归属由索引持久化，History 仍持有原始媒体。
7. 在 **镜头工坊** 选择合适 Take，添加到时间线，使用已存在的音量、裁剪、速度、预览/Media3 混音导出，最终检查视频时长与声音轨道。

## 独立生成 → 项目

原先在 **创作** 页直接打开模型也不必提前建立项目。现在在已存在项目时可通过“关联项目”选择项目级任务；对类型明确为 `video` 的云端模型还可关联一个非运行中的 Shot。可以取消草稿关联，保留独立任务的原始工作方式。已提交的任务身份不会被此操作改写。

项目级图像/音频任务成功后，通过 **结果 → 加入项目** 决定它是下一步的参考图、音轨还是其它资产。当前阶段产物没有自动跨供应商上传，也不自动改变镜头已选 Take。

## AI 导演：带上下文的可审核辅助

进入项目的 **AI 导演** 可以让已配置的 AI 根据剧本、画风、角色/场景档案、素材标签、最近镜头、Take 状态、时间线音视频长度、项目预算与已配置视频模型列表规划后续镜头。若配置的 AI 不可达，项目其它功能不受影响。

AI 的输出仍须符合当前行格式解析器。每一行建议可编辑画面提示、机位/衔接和**计划叙事秒数**，可取消选中某行，应用时一次写入本地 Draft Shot。该秒数不会直接假装成为 Provider 的视频生成字段：例如计划 12 秒的镜头，单次生成只支持 5 秒时，仍需人工分段续接或调整方案。

AI **不会**默认删除文件、修改已选 Take、替你选未确认的收费服务，或提交任何付费请求。

## 当前限制（务必理解）

- 三套“组合工作流”是保存到项目的**手动执行配方**。跨 Provider 自动产物传输、类型化输入输出节点连接、每阶段自动再执行、自动调度或失败策略仍需后续设计/开发。
- 项目的云能力目录取真实 `kind = image/video/audio` 条目，但**不能凭模型名证明**它支持多图、首尾帧、特定比率、费率或画质；必须在创作页查看 Provider 真实字段与拦截提示。
- “AI 导演”有比旧版更丰富的上下文，但不是具有视觉理解的自主 Agent；没有自动看懂全部图片内容，也不拥有未配置的外部模型权限；人工审核建议是必要步骤。
- 导演显示的是计划叙事时长，不代表实际合成时间线或已成功生成时长。
- 虽然已有三组模拟器回归，**120 秒/12 镜头、至少两 Provider、四个双 Take 的真实设备有声成片端到端样例仍未验收**，继续跟踪 [Issue #80](https://github.com/Starysoor/Iris/issues/80)。
- 重要项目/历史素材请备份，不要在不具备备份时卸载应用回退版本。

## 回归建议

1. 一个不含云服务的空白项目：建镜头、保存、强杀重开，数据不能丢。
2. 选择三类配方并切换三个云模型，检查保存和重新进入后仍一致；既有 Shot 的独立 Provider 覆盖不能被配方修改。
3. 从独立创作关联项目，再到任务筛选、结果页归属候选 Take；退回项目后原 selectedTakeId、时间线及其它历史记录必须不变。
4. 导入一个视频到时间线以及 WAV 到音频轨，验证 Media3 预览和导出有声 MP4；关闭项目后可恢复。
5. AI 导演生成建议后修改一行、取消一行，确认只新增勾选草稿、秒数仍在重启后保留、不会自动提交收费任务。
6. 原有「创作 / 任务 / 结果」独立路径的提交、恢复、相册分享及过滤不应回归。
