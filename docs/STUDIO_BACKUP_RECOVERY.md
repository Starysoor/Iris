# Studio 项目索引自动备份与人工恢复（#109 A1）

Iris 每次修改 `projects.json` 之前，会严格校验原索引并将原样字节写成一个 app 私有目录中的 `projects.backup-<时间>-<序号>.json` 快照，保留最新 3 份；新建第一份索引后也尝试建立第一份备份。写入和备份采用临时文件、fsync 和原子替换（不支持原子移动时使用安全兼容路径）。无法保存已有索引备份时，拒绝继续覆盖原有项目数据。文件损坏不再被误判为零项目。

**操作入口：**「项目」索引异常时的「恢复项目索引备份」；正常项目也可进入项目主页右上角菜单选择相同入口。只能选由 Iris 验证可完整解码的快照，并须手动选择、再次确认。恢复前将正在使用的 `projects.json` 原始字节保存在 `projects.before-restore-<时间>-<序号>.json`，包括可能损坏的索引，以便后续手动排障。已恢复项目会重新载入内存，不会自动删除任何媒体。

**关键限制：**本功能只备份整个项目的 JSON 索引，不包含视频/图片/音频文件，也**不**替代换机备份；恢复旧版本会丢失较新编辑，与运行中的任务可能产生关联差异。不会取消付费任务或自动重试。不要清理应用数据或卸载来排障。独立的项目 ZIP 包导入导出与后台导出服务仍属于 #109 的后续任务。

**测试：**覆盖首次创建、备份轮换、错误/损坏恢复、非法备份拒绝、原字节保护、恢复后新写入与重启再加载。JVM/Android CI 以对应 PR 最新运行结果为准。
