# Studio 多阶段输入契约预检（Issue #101 · PR #103 / #104）

本功能在项目首页 **组合工作流 → 阶段模型 → 检查输入** 中提供。仅检查 **已经配置的云端 Provider** 通过 `detail(workflowId)` 返回的真实模型字段，不会访问收费生成端点，也不会偷偷上传素材。

## 操作步骤

1. 打开 **项目** → 选择工作流配方（文本→视频、参考图→视频、关键帧→视频→音频）。
2. 对某一生成阶段选择已配置的云模型后点击 **检查输入**；若 Provider 不可达，则显示明确的读取失败，而不是按模型名称猜测能力。
3. 核对真实输入字段：`image` 与 `audio` 输入位总数和必填数、字段名和 Provider 声明的角色、数值上下限、枚举选项、计价说明。缺少计价元数据时明确显示费用未知。
4. 系统按角色/文件类型给出本项目素材库中**候选文件**数量。必填多图/音频字段还会检查能否由**不同的本地文件**满足，不会将一张图的重复索引当成两张图。
5. 对真实声明为 **image/audio** 的字段，可以从项目已有素材中选择对应角色/用途的文件并保存；每一项绑定都带完整模型路径、真实字段名和素材 ID，取消绑定不会删除原素材。\n6. 选择 **进入生成** 时重新校验：模型仍可用、输入位仍存在、素材属于本项目且文件仍可读取。校验通过后才将逐字段映射传给 **创作**，由既有上传机制处理；加载失败会阻止付费提交，直到用户修复对应字段。\n7. 项目绑定不是收费执行。必须在 **创作** 页核对参数/实际费用并通过原有付费确认门禁，才能生成。

## 如何读懂结果

- **可配置**：当前已知字段可由既有创作编辑器填写；不代表尚未由用户选择的素材已经上传或符合所有真实厂商格式限制。
- **当前应用无法编辑的必填字段**：例如必填 `video` 上传字段尚不被现有 `CloudWorkflowMapping` 接受，预检不会假装它可以直接运行。
- **未知契约**：Provider 未返回任何输入规则，无法保证支持首尾帧、音频或参考图数量。
- **缺少不同的媒体文件**：仅是项目**素材库存量不足**的提示；您仍可在创作页选择本机其它文件，不因此强制创建项目或购买模型。
- **价格**：仅显示 Provider 提供的报价标签。没有提供则未知，具体收费仍以每次生成前的确认界面为准。

## 暂未实现的部分

这是**能力预检 + 用户明确选择的字段级素材绑定**，并非跨 Provider 自动执行的 DAG。仅可将已验证的 image/audio 输入名映射至本项目的已有素材；不会自动把一个模型的产物上传到另一个模型，也不会自动执行收费任务。图像 MIME/尺寸和视频编解码等 Provider 细项仍需要在创作与实际上传阶段核对。

后续 #101 工作：跨供应商自动阶段连接前的 MIME、分辨率、时长与依赖图校验，以及经用户确认的阶段执行快照。每个收费阶段仍须独立确认。此文件的预检结果不能替代 #80 的 120 秒、12 镜头真实 Android 端到端验收。
