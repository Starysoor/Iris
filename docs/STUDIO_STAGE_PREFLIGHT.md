# Studio 多阶段输入契约预检（Issue #101 · PR #103 / #104）

在项目首页或镜头工作台的图像、视频和音频阶段选择 **检查输入**，可以查看模型简介、实际字段及输入限制。云端阶段读取供应商返回的模型定义，本地阶段读取所连 ComfyUI 的工作流和节点定义。

## 操作步骤

1. 打开 **项目** → 选择工作流配方（文本→视频、参考图→视频、关键帧→视频→音频）。
2. 为阶段选好工作流或云端模型后，点击 **检查输入**。连接失效时会提示读取失败。
3. 核对图片、音频和视频输入的字段名、角色、必填状态以及适用的选项或范围。云端计价取自供应商提供的数据。
4. 查看项目素材的匹配数量。多个必填媒体字段会检查是否有足量的不同文件。
5. 从项目素材库为需要的字段绑定文件。镜头可以为同一字段选择自己的素材，或恢复使用项目绑定。每项绑定保存模型路径、字段名和素材 ID。
6. 进入 **创作** 前，Iris 会复核字段和文件是否仍可用。在创作页确认参数后即可提交。

## 如何读懂结果

- **可配置**表示可以在创作页填写供应商或工作流声明的字段。实际提交时仍会校验文件。
- **当前应用无法编辑的必填字段**会列出 Iris 尚未处理的输入类型。
- **未知契约**表示厂商尚未返回输入规则，首尾帧、音频和参考图数量需要向厂商核对。
- **缺少不同的媒体文件**表示项目素材库里缺少可以分配给各必填字段的独立文件。在创作页可以从本机补选。
- **价格**取自厂商目录。目录缺少报价时显示未知，提交前可再次核对费用。

## 跨阶段使用结果

每个阶段单独发起生成。生成的图像可以设为镜头首帧或尾帧，生成的音频和视频可以加入时间线。模型服务会在提交时校验图像尺寸、视频编码等要求。
