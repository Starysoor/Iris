# Iris 用户体验维护 — 2026-11-18

## 保存大图片/视频

- 「创作」和「结果」中的媒体保存改为基于源文件的 **256 KiB 分块流式复制**，避免大视频使用默认 8 KiB 小缓冲；不会将视频或大图片整文件读入内存。
- Android 10+ 通过 MediaStore IS_PENDING 保护写入中的媒体；只有完整复制成功并公开后才显示“保存成功”，失败时删除本轮创建的相册条目。
- 在预览弹窗内部直接显示实时进度/成功/失败；点击“保存”后禁用重复保存，避免用户看不到被弹窗遮挡的底层 Snackbar。原底层通知仍可见，关闭弹窗后可回看反馈。
- 对“保存速度”的改善来自减少 I/O 缓冲调用次数，不承诺一定达到某个带宽；媒体编码、手机存储速度和 Android 相册扫描仍受系统限制。

## 创作页项目关联提示

在「设置 → 应用与界面」新增“显示关联项目提示”，默认开启，仅控制**尚未关联项目时**工作流顶部的可选关联建议。若当前确实已关联某个项目，状态与退出关联按钮仍保留，防止隐藏活动创作的项目归属和潜在计费约束。

## 提示词技能帮助

在「AI 提示词 → 技能列表」和“新增/编辑技能”标题中添加带问号圆形帮助按钮。支持中英双语，逐项解释：7 个适用场景、7 个输入来源、3 种执行方式、4 种输出方式，以及技能匹配关键词与“使用步骤”。

## 版本与更新

在「设置 → 版本」中点入唯一的“版本与更新”页面，展示实际安装的版本号、产品功能简介、开源仓库、反馈 Issue 入口、历史发布列表，并在同页执行现有 GitHub Release 检查/下载/安装；不再有独立的软件更新设置行。

Iris 是公开仓库，移除 GitHub Token 文本框、Token 持久读取和 Release 下载认证头；通过公开 Releases API 查询并优先通过公开 browser_download_url 下载 APK。**AutoDL / 其他云厂商的授权 Token 不受影响。** 原先设备里历史遗留的 GitHub Token 数据不会被再次读取（并不会主动清除所有旧版本的安全存储键）。

## QA 检查项

- 大图片和大视频保存时进度在预览内部更新；成功在预览内展示；失败必须可见并删除不完整媒体。
- 进度回调与文件流在 IO 线程，连续点击保存只能进行一次写入。
- 设置开关关闭后可选项目提示不再出现，但实际已绑定的项目仍可见。
- 帮助逐项覆盖全部 SkillScope/SkillInputSource/SkillExecution/SkillOutput 枚举。
- 版本页只出现一次入口，并保留检查/下载/安装；无需 GitHub Token；反馈链接打开 Starysoor/Iris。
- Android 29、34 手机/平板回归与真机大媒体测速应分别核验，CI 不能等同于真机 I/O 性能测试。
