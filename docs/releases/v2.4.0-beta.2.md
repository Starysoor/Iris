# Iris v2.4.0-beta.2 · 第二轮真机测试版

> **预发布测试版，非正式稳定版 v2.4.0。** 相对于 2026-11-08 发布的 beta.1，本轮集成经过主分支自动化检查的 Studio 跨页联动、模型字段绑定与结构化 AI 导演。包名继续为 `com.comfyremote.app`，versionName `2.4.0-beta.2`、versionCode `30`（高于 beta.1 的 29，可正常做同签名覆盖升级）。稳定版仍为 v2.3.2。

## 安装

从本 Release 的 Assets 下载 `Iris-v2.4.0-beta.2.apk` 和配套 `.apk.sha256`。GitHub Actions 构建并验证签名、安装包名称与版本号；校验值用于检查文件完整性，不代替来源可信性。**不要卸载原 App 来绕过签名不符**，否则项目、历史、凭据可能丢失。建议先备份旧数据；若系统提示签名冲突或不允许覆盖升级，应停止安装并提交问题。

## beta.2 实际新增

- **项目上下文贯通**：从项目镜头到创作再返回项目；独立创作可选择关联作品；任务列表按独立/项目过滤，结果可作为项目素材、特定 Shot 候选 Take 或时间线片段回流。未关联任务、结果和原页面主操作保持可用。
- **3 种工作流配方**：文本→视频；参考图→视频；关键帧→视频→音频。每个阶段独立选择真实 Provider 图像/视频/音频模型，**手动选择/提交**，不会自动串接多厂商付费服务。
- **真实输入契约预检**：从 Provider 模型详情读取字段类型、是否必填、图片用途角色、数值区间、选项和可获取的价格提示；缺失真实契约时不会猜测。项目图片/音频可按真实字段名精确绑定并带入创作；不支持的强制输入、无效素材或模型切换错配会阻断自动交接。
- **结构化 AI 导演**：支持版本化的 `shots[]` JSON 输出，说明建议依据与风险；引用项目内图片 ID 经过检查，用户逐条编辑和选择，原子写为镜头草稿；不会自动付费生成、删除 Take 或覆盖已选主版本。
- 保留 beta.1 的视频/背景音混合、同源合成预览、媒体导入、存储损坏保护、Take 安全和连续性抽帧分页。

## 任务中心批量操作安全修复（#107）

- 在任务页选择项目/服务器后，批量重试失败、取消排队、清理已结束任务仅针对**当前项目和服务器**，不会误操作其他项目。
- 从任务页重试或复制 Studio 任务时重新检查关联项目/镜头、镜头运行状态和项目估算预算；超预算或已失效时拦截，保留统一付费确认。此保护仍基于估算成本，不能替代厂商实际账单。

## 本轮优先真机验收

1. 从 **beta.1 覆盖安装** beta.2，验证旧项目、任务、素材、Take、时间线、已有结果均保留；强杀重启再确认。
2. 创建离线短片项目，从作品镜头进入创作；新建独立任务关联/取消关联项目，任务按项目筛选，结果作为候选 Take 回流，检查所选版本与历史媒体没有被覆盖。
3. 在至少两个不同 Provider 的可用目录中选择 image/video/audio 阶段，检查双图首尾帧/角色参考图的**字段名与顺序**，故意填错字段、移除项目媒体或断网，确认无法误提交收费任务。测试远端收费时需再次主动确认。
4. 为一个有剧本/人物/场景/图片的项目运行 AI 导演，审核结构化计划、依据与风险；编辑并只选部分镜头落地，再重启核对原项目无损。
5. 完成 **真实 120 秒、12 镜头、至少 2 模型、至少 4 个双 Take 镜头**的有声作品：角色三视图+至少 5 场景、首尾帧接力、音效/对白、混音试听、强杀恢复、导出 MP4、实际播放及音画同步。留存机型、Android 版本、耗时、文件时长、问题时间码；这是 #80 尚未完成的正式发布阻塞。
6. 低内存设备的多镜头连续性检查、500 MiB 素材导入和取消、权限/相册/分享、Tailscale 网络恢复。回报卡顿/闪退需附脱敏日志。

## 明确未实现 / 已知限制

- **非自动跨厂商 DAG**：仍是手动、逐阶段、逐次付费确认的流程；不保证任何两个模型输出能自动互喂。不能替代完整的多模型连线语义和参数适配。
- **视觉 AI 未完成**：文字 AI 使用用户填写的素材描述/项目关联及真实图片 ID，不会自动阅读全部媒体帧，推荐的模型路径需再次检查真实接口能力。
- **单视频轨 + 基础音轨**：预览可能需要先合成临时 MP4，不是毫秒级即时多轨剪辑；原始音频、配乐和变速需真机实际试听。
- **媒体存储**：复制入 App 私有空间；目前未提供长期直接引用任意外部 SAF 文件的完整功能。
- **长片导出/任务恢复**：本地导出在前台会话受进程/存储/硬件限制，异常后需主动重试；付费请求已被厂商接收时不要盲目重试，以免重复收费。
- **尚无真实完整两分钟验收证据**。以 #80 和 #101 为准，不能仅凭测试/模拟器绿色宣布全部需求完成或发布稳定版。
