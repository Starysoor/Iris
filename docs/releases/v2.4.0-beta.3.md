# Iris v2.4.0-beta.3 · 大媒体保存与工作流体验测试版

> **Android 10+ 的预发布测试版，不是稳定版 v2.4.0。** 发行包名 `com.comfyremote.app`，`versionName 2.4.0-beta.3`，`versionCode 31`，高于 beta.2（30）和正式版 v2.3.2（28）。保持与此前正式版/测试版同一仓库签名，不要求卸载 App。

## 下载与安装

下载 Release 页面 Assets 的 **`Iris-v2.4.0-beta.3.apk`**，可使用同页 `.apk.sha256` 验证文件完整性。发布流水线在签名后检查 APK 的包名、版本信息和证书，再上传；只有通过验收才标记预发布。

**安装前备份项目与结果。** 建议从 beta.2 同签名覆盖安装并验证数据保留；提示证书不符时立即停止，不要卸载旧版绕过冲突。测试版对旧稳定版的直接回退可能受到 Android versionCode 和数据模式限制。

## 相对于 beta.2 的改进

### 保存大图片、大视频与可见反馈（PR #123）
- 相册媒体保存改为 256 KiB 缓冲流式复制，复制过程中不再把大文件整体读入内存。Android 10+ 通过 MediaStore 待发布标志保护未写完的文件；失败时清理新建条目。
- 图片和视频全屏预览直接显示保存百分比、成功和失败，不再需要关闭预览才能看到底层提示；保存中阻止重复点击。
- 新增 Android 模拟器实际 MediaStore 大媒体往返验证：**16 MiB 图片、48 MiB 视频**，核对进度、公开状态和保存前后 SHA-256 完全一致。模拟器测试仅证明该尺寸媒体的复制完整性，不代表所有手机的读写速度或超大文件实际耗时。

### 工作流和 AI 提示词技能
- 在「设置 → 应用与界面」可开关**工作流顶部的可选关联项目提示**，已实际关联的项目仍显示，避免隐藏归属和预算风险（PR #123）。
- 技能列表、编辑页均有圆圈问号，可查阅双语使用指南，完整覆盖场景、输入来源、执行方式、输出方式所有 21 个标签（PR #123）。
- 新增内建 **MiniMax H3 视频扩写技能**：T2VA/I2VA/首尾帧 FL2VA/L2VA，自然语言分镜与运镜、对白、环境音效和非画内配乐分别描述；优先推荐给 MiniMax/H3 工作流，沿用用户配置文本模型（PR #122）。

### 版本与更新
- 「设置 → 版本」为可点击的统一版本页，提供当前版本说明、开源仓库、Issue 反馈、历史 Releases 和检查/安装更新；去掉单独的软件更新入口和 GitHub Token 字段（PR #123）。
- 进一步修复测试版更新检测：已安装 beta 的用户可以发现新 beta 和未来稳定版；已安装稳定版用户仅自动检查稳定版。按 SemVer 正确比较 beta.2、beta.3、beta.10 与最终正式版。保留公开 Release 的无密钥下载。
- 旧 GitHub Token 在升级时清除；**AutoDL、其他云厂商 AI Key 不受影响**。

### Studio 项目可靠性（PR #115–#119）
- 项目筛选/归档、多项目安全复制方案；视频/音频片段长按拖动排序；可移植项目 ZIP 导入导出，含媒体与路径 ID 校验。
- 时间线真实 PCM 音频波形、按需双 Take 对比和大项目性能基准；用户授权后可通过已配置的 AI 端点做拼接处视觉评审，AI 报告与启发式检测分离且可能产生用户 API 费用。
- 上述功能不代表整个跨服务自动执行、120 秒真机成片或前台后台长片导出已最终验收；请勿将未合并 PR #120 的能力误认已发布。

## 自动化验收说明

发布前要求检查全部**最新提交**：
- JVM 单元测试和新增 beta 版本检查回归。
- Debug APK、Release 候选包编译、Android Lint。
- Android 29 手机、Android 34 手机/平板的安装、冷启动、强制停止后重启、暗色/大字体/横屏和本地任务 smoke。
- Media3 本地有声视频导出：混音结果同时包含原声 440 Hz 和独立音轨 880 Hz。
- 上述 16 MiB 图片、48 MiB 视频的真实 MediaStore 回写与数据校验。
- 签名 Release 工作流：打包、签名、包名/版本码/版本名检查、APK SHA-256 和 Release 资产。

## 本轮需要你在真机重点测试

1. 从 beta.2 覆盖安装 beta.3，检查所有已保存项目、云端凭据、历史结果、时间线及 Take；强杀重启再确认。
2. 打开大图片和大视频预览，点右上保存：保存中百分比可见、成功/失败不被遮挡、重复点击不产生副本；在系统相册打开确认。建议各测试 50 MiB、200 MiB、500 MiB，记录机型/系统/文件大小/时长/耗时。
3. 在「应用与界面」关闭关联项目提示后打开未关联工作流，应无顶部建议条；已绑定项目的标识和解除绑定功能仍显示。
4. 打开提示词技能帮助，核对各个标签解释；在 MiniMax H3 工作流试首尾帧扩写，确保无配乐与音效分别保留，不会主动提交付费视频。
5. 在「版本与更新」中检查版本号、仓库、反馈入口、更新检查及 APK 安装入口；不同网络或无 GitHub 账号都应可访问公开更新源。
6. 完整两分钟/12 镜头/两个模型/四组双 Take 的真实安卓设备电影级 E2E、真机长片恢复、不同硬件编码、付费平台连通与 Tailscale 仍须提供独立验收证据，**不是本次 beta 的完成承诺**。
