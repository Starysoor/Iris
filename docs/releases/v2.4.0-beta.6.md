# Iris v2.4.0-beta.6 · ComfyUI 内置多 LoRA 支持

适用于 Android 10 及以上。包名为 `com.comfyremote.app`，版本码为 `34`。可用同一发行签名覆盖安装 beta.5。在发布页的 Assets 下载 `Iris-v2.4.0-beta.6.apk`，使用同页的 `.apk.sha256` 核对文件完整性。

## 创作

- 支持 ComfyUI 0.44 的内置 LoRA 堆叠节点 `LoadLoraModel` 和 `LoadLoraTextEncoder`。画布和 API 导出都能识别多行 LoRA，每行可分别编辑文件、强度和启用状态。
- 在「高级参数」可添加 LoRA 行或移除末行。草稿会保存行数，重新打开应用或刷新工作流定义后可继续编辑。恢复默认会移除手机上添加的行。
- 增删行遵循服务器声明的行数限制。行数或字段值不符合工作流要求时，会在提交前显示具体问题。

## 验证

473 项单元测试、构建、Android Lint 和三组 Android 模拟器检查通过。`Krea2-二次元` 工作流通过本地 ComfyUI 实际出图验证，覆盖手机端添加第二行 LoRA 后出图，以及重启应用后的草稿恢复。[修复与实测记录](https://github.com/Starysoor/Iris/pull/132) · [自动检查](https://github.com/Starysoor/Iris/pull/132/checks)
