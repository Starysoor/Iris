# Iris v2.4.0-beta.1 — Android 真机验收测试版

> **Pre-release / 测试版，并非 v2.4.0 正式发布。** 正式稳定版仍为 [v2.3.2](https://github.com/Starysoor/Iris/releases/tag/v2.3.2)。此构建以 `main@35aa0056554e7c60250244738db05c92f0e4daec` 为功能基线，使用相同 `com.comfyremote.app` 包名及仓库已有的 Release 签名流程；版本 `2.4.0-beta.1`，`versionCode 29`。

## 下载 / 安装

在下方 **Assets** 里获取 `Iris-v2.4.0-beta.1.apk`。仓库 CI 将检查 APK 包名、versionCode、versionName 和签名有效性，并提供 `Iris-v2.4.0-beta.1.apk.sha256` 校验文件。

建议先对重要项目、素材、API 配置和结果做安全备份。当前版本针对数据损坏有防覆盖保护，但**软件升级和回滚风险不可完全消除**。已安装官方 v2.3.2 且签名一致时，直接安装应保留 App 数据；若 Android 提示签名不符，请停止安装，**不要为安装测试版而卸载正式版**。不要在唯一的生产设备中测试孤本数据。

## 本次测试范围

- Iris Studio：空白/离线项目、剧本概览、独立场景/角色素材库、Shot → Take 多候选、每镜头模型覆盖、参考图、首尾帧、连续性检查与 AI 导演建议。
- 时间线：视频轨、独立音频轨、裁剪、倍速、原声增益/静音、视频与背景音混音 MP4 导出。
- 预览：使用与导出同一套 Media3 合成引擎先渲染临时有声 MP4，确保效果一致。长视频首次预览**需要等候合成**，尚非即时实时 NLE 预览。
- 可靠性：项目/结果坏索引保护、孤儿导出临时文件清理、Take/历史媒体引用安全、模型目录刷新竞态与导演抽帧内存分页。
- 各类素材：图片保留 32 MiB 限制；流式视频上限 1 GiB，音频 512 MiB，字幕 8 MiB；大素材优先复制至应用私有目录。
- 兼容原有「创作」「任务」「结果」主页面，不默认调用任何付费模型。AI 导演仅给出建议。

## 真机建议验证清单（每条可附截图/日志）

- [ ] **安装升级 / 数据持久**：从 v2.3.2 覆盖安装；打开旧结果与旧项目，退出后强制停止、重新启动，确认记录仍在、没有异常空列表。
- [ ] **项目完整流程**：新建 16:9、目标 120 秒的项目；加入角色三视图与至少 5 个场景参考，建立 12 个镜头；切换两个模型（可先使用 Mock / 本地免费工作流），为至少 4 个镜头保留多 Take，切换和删除候选时检查其它媒体仍存在。
- [ ] **配乐 + 原声**：在视频轨选择有原声的片段，在独立音轨加入 WAV/M4A 配乐/音效，先试听临时预览，再导出 MP4；检查声轨都保留、倍速/音量/静音符合设置，未发生卡音/静音/音画不同步。
- [ ] **媒体与分享**：相册保存到 Movies/Iris；系统分享面板；播放完后重新进入结果/项目。
- [ ] **联网与任务恢复**：分别通过局域网和 Tailscale 访问 ComfyUI；在运行/取消/断网/后台时验证任务状态。不要为了测试重复提交已计费请求。
- [ ] **性能与兼容**：低内存设备长镜头连续性分页、50/200/500 MiB 媒体导入、大字体与横屏/平板。
- [ ] **异常与恢复**：导出中止、存储不足、返回上一页以及重启后无损恢复；原始素材不应被删除。
- [ ] **结果复核**：完成一条真正约 120 秒的、有可听声音的 MP4；记录手机型号、Android 版本、原始编码、预览/导出时间、成片长度及问题时间码。

## 已知限制 / 安全须知

1. **真机 HW 编码、OEM 后台限制、Tailscale、系统相册权限和完整 120 秒成片还需通过本次真实设备验收**；模拟器成功不能替代它们。
2. Studio 目前是一个顺序视频轨加一个顺序音频轨的基础混音，并非任意重叠的音乐/配音/音效多层混音，自动淡入淡出与实时监听不作为本次承诺。
3. 时间线导出与试听由本地 Media3 执行；关闭 App、资源不够或编码器不兼容会导致导出失败，应检查并重试；本版不承诺后台继续编码。
4. 大媒体复制到 app-owned 存储；还未实现对用户外部 SAF 文件的长期直接引用。
5. 厂商收费由各自服务决定。预算是估算点数而非正式账单。取消本地追踪不保证远端作业取消，切勿不确认就重复提交。
6. 下载/安装前建议备份原有项目。要退回稳定版时，较高版本号可能导致无法直接降级；不要通过卸载来回退而丢失数据。
