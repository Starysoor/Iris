# Iris · 灵瞳 v2.4.0 — Release Candidate（待人工验收）

**状态：候选版准备中；本文件不表示已发布。** 正式 Release 必须同时满足 [#80](https://github.com/Starysoor/Iris/issues/80) 的设备与成片验收，不能仅凭 CI 绿色打 tag。项目原有的「创作」「任务」「结果」页面继续保留，只有「分镜」升级为项目工作台。

## 新增功能（已经合并到 main）
- **Iris Studio**：以项目为中心，编辑剧本/画幅/目标时长/预算，离线建项。
- **素材/一致性档案**：角色、场景、视频、音频、标签和多图引用。
- **Shot / Take**：每个镜头独立模型、候选生成版本、切换主版本，保护媒体所有权。
- **时间线**：视频轨、逻辑音频轨、片段顺序/裁剪/变速/增益/静音和顺序预览。
- **MP4 导出**：合成视频轨与原视频自带音频，带源文件/裁剪边界校验；结果入历史、可分享或存相册。
- **AI 导演**：镜头计划建议、逐秒帧条/接缝检查、项目预算闸门；绝不自行提交付费任务。

## 2.4.0 数据安全修复（PR #90）
- 修复预算设置被意外清空、Take 删除误删 History 文件、过时任务结果覆盖用户已选 Take 等。
- 保留镜头独立模型配置；素材支持大文件流式导入；对丢失片段和超长裁剪拒绝不完整 MP4。
- 包括保存失败、旧版迁移、连续性抽帧内存控制和项目离线编辑回归测试。

## 当前限制
- 正式发布前**不可宣称完整独立音轨混音已验证**；PR #91 的实际编码器验收仍需最新运行结果和真机验证。
- 时间线只有一条顺序音频轨，尚不支持任意多轨叠加、交叉淡化；当前顺序预览与实际导出效果不完全一致。
- 导出依赖前台 ViewModel 会话，关闭应用会中止任务，需要手动重新导出，不具备后台断点恢复。
- AI 导演调用用户自配 AI Endpoint，仅产出建议；未完成真实模型付费端到端验证。
- 旧项目迁移有备份；降级旧版 APK 时不保证能看到新建项目，升级前请留存完整数据备份。

## 安装和发布提醒
