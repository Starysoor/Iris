# Iris · 灵瞳 v2.4.0 发布候选

当前测试基线为 `v2.4.0-beta.6`，包名为 `com.comfyremote.app`，版本码为 `34`。正式版使用版本号 `2.4.0`，版本码须高于此测试版。[测试版说明](v2.4.0-beta.6.md)

## 项目工作台

- 从剧本、角色和场景资料开始建立项目。每个镜头可为图像、视频、音频指定工作流，核对必填输入和素材。参数和种子按阶段及模型保存。候选 Take 可加入时间线，任务可以按镜头查找。
- 时间线支持视频和独立音频。导出 MP4 时可离开当前页面，从通知查看进度、取消或返回时间线。系统终止进程后可重新导出。
- 项目索引支持回滚备份，项目和引用媒体可导出为 ZIP。降级会打开旧版能读取的分镜快照，升级或换机前请备份项目。
- AI 导演可生成待审核的分镜建议、关联项目参考素材和检查片段衔接。用户可逐项确认后保存为本地镜头草稿。

## 工作流与模型

- 创作页支持新的 ComfyUI 连线、嵌套子图及模型清单刷新。可在「高级参数」编辑模型、LoRA 和采样器。缺少参考图时可在对应字段重新选择。
- AutoDL 托管工作流支持参考视频。云端目录使用供应商提供的模型名称、简介和版本，保留原始 ID 供调用。
- 项目可逐阶段使用已连接的 ComfyUI 和已配置的云服务。每个收费阶段在创作页单独确认。

## 发布验收

测试基线通过 473 项单元测试、Android Lint、Debug 和 Release 构建。Android 14 软件模拟器通过 120 秒、12 镜头、16 Take 的后台导出和 MP4 完整解码。[导出验证](../STUDIO_FOREGROUND_EXPORT.md)
