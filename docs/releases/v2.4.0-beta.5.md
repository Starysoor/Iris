# Iris v2.4.0-beta.5 · 多 LoRA 与云端模型修复

适用于 Android 10 及以上。包名为 `com.comfyremote.app`，版本码为 `33`。可用同一发行签名覆盖安装 beta.4 或其云模型热修包。在发布页的 Assets 下载 `Iris-v2.4.0-beta.5.apk`，使用同页的 `.apk.sha256` 核对文件完整性。

## 创作

- 「模型与采样」已放回「高级参数」。底模、LoRA 和采样相关选项按节点分组，同名节点可用编号区分。
- 本地 ComfyUI 的 rgthree Power LoRA Loader 现在会读取每个 LoRA 槽位。画布和 API 导出均保留 LoRA 文件、启用状态、模型与 CLIP 权重，以及原有连线。
- AutoDL Models 和 OpenAI 的模型目录在后台加载。连接测试成功后，已启用的图片模型可在创作页显示。加载失败时，可对当前云服务重试。

## 验证

454 项单元测试、构建和 Android Lint 已通过。Android 10 手机、Android 14 手机及平板模拟器通过云模型目录及项目工作台回归。多 LoRA 测试覆盖两种导出格式和槽位参数回写。[修复 PR](https://github.com/Starysoor/Iris/pull/131) · [回归结果](https://github.com/Starysoor/Iris/pull/131/checks)
