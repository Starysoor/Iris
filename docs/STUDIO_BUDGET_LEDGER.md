# Studio 项目预算与远端受理记录（#109 E2）

项目估算预算不再只依赖当前任务列表里可见的 `estimatedCloudCost`。当厂商返回远端任务 ID 后，Iris 的本地 `CloudSpendStore` 条目还记录项目 ID；按 Provider、Endpoint 和远端任务 ID 去重。项目预算界面、创作页和任务页的付费重试都通过同一个规则：

- 已受理且有记录的任务采用该条目中保存的**受理时估算积分**；
- 任务还在本地准备、没有可匹配条目或条目积分未知，回退到原任务估算；
- 已从任务列表清理但仍留在本地积分记录中的已受理任务，继续计入项目预算；
- 老版本积分记录没有项目身份，**不能猜测属于哪个项目**；这部分仍依赖保留的任务列表数据。
- 远端任务 ID 相同但 Provider/Endpoint 不同，不被错误去重。独立生成也不会污染项目预算。

**重要：CloudSpendStore 的 points 仍然是 Iris 在远端受理时记录的价格估算，不是厂商真实账单。** 本地删除/重装/积分记录上限和厂商定价变化都可能使统计不完整。用户仍需在厂商后台核对账单；预算阻断是安全辅助，不代表实际费用保证。没有自动付费调用。

兼容性：新字段是 JSON 可选值；历史记录缺失字段时安全回退。JVM 测试覆盖重复远端 ID、已清理任务、跨项目隔离和未知费用。
