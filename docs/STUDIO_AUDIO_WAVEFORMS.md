# Iris Studio — 音频波形预览 (#109 C3)

时间线音频片段下方展示**真实解码 PCM 峰值**，而非根据文件大小或压缩包数据伪造幅度。每段波形采集 48 个分桶，按片段入点、出点和解码时间戳建立幅度分布；不更改音量、速度、真实导出音频或项目 JSON。

读取采用 MediaExtractor/MediaCodec、IO 调度及流式逐块采样，内存占用为固定 48 个分桶并缓存最近 64 个片段/修剪窗口。最多分析三分钟的本地音频片段；解码失败、无音轨、超限或静音不会展示伪波形。新的修剪范围自动重新分析。离开屏幕会取消协程，并释放解码器、Extractor。

这只是波形可视化，不代表 #95 时间线音画预览与成片完全一致，也不能代替实际真机长音频和多厂商编解码压力测试。
